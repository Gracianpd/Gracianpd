### Gracián Pérez Dewey

Software engineer in Madrid working on scientific computing and estimation algorithms for satellite navigation (EGNOS performance at ESSP, precise positioning at GMV). That work is proprietary, so this profile holds my physics and computational-physics projects (B.Sc. Physics, UCM; M.Sc. Computational Physics, UNED).

**Numerical methods and simulation**
- [numerical-methods-pdes](https://github.com/Gracianpd/numerical-methods-pdes): finite differences, heat conduction (Laplace in polar coordinates), diffusion with explicit and Crank–Nicolson schemes, FEM, all validated against analytic solutions
- [schrodinger-eigenvalue-solvers](https://github.com/Gracianpd/schrodinger-eigenvalue-solvers): node counting and bisection for the 1D Schrödinger equation, with convergence and limit checks
- [monte-carlo-stochastic-simulation](https://github.com/Gracianpd/monte-carlo-stochastic-simulation): Monte Carlo integration, 2D Ising Metropolis, SDE integration vs the Fokker–Planck solution

**Signal processing**
- [gnss-interference-information-metrics](https://github.com/Gracianpd/gnss-interference-information-metrics): detecting interference on DSSS/GNSS-like signals with entropy, KL divergence and mutual information (MATLAB)

**Quantum physics**
- [quantum-many-body-numerics](https://github.com/Gracianpd/quantum-many-body-numerics): exact diagonalisation, Hartree–Fock, Anderson localisation, path-integral Monte Carlo
- [adiabatic-quantum-simulation](https://github.com/Gracianpd/adiabatic-quantum-simulation): adiabatic quantum computation on spin glasses (Qiskit)
- [entanglement-geometry](https://github.com/Gracianpd/entanglement-geometry): entanglement adjacency matrix and emergent geometry of quantum states
- [bsc-thesis-excitons-2d-materials](https://github.com/Gracianpd/bsc-thesis-excitons-2d-materials): finite-difference model of excitons in 2D semiconductors, fitted to experimental data

**Networks and neural networks**
- [complex-networks-analysis](https://github.com/Gracianpd/complex-networks-analysis): power-grid and GitHub social-network analysis vs random-graph models
- [hopfield-networks](https://github.com/Gracianpd/hopfield-networks): Hopfield and diluted attractor networks, MLP depth study
